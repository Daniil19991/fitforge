# FitForge Lite — конструктор тренировок

Облегчённая версия FitForge **без 3D**. Всё остальное на месте:
- **48 упражнений** с анимированной техникой (персонаж: лягушка или человек), пошаговыми подсказками и типичными ошибками;
- **анкета** — подбор под пол, возраст, вес, цель, уровень, инвентарь и ограничения;
- **конструктор** — 8 типов тренировок, замена упражнений, шаблоны;
- **календарь и план на недели**;
- **режим тренировки** — подходы, веса, таймеры отдыха и работы, подсказки рабочего веса;
- **аналитика** — тренировки по неделям, нагрузка по группам мышц, прогресс в упражнениях, вес тела, история;
- **резервная копия** данных (экспорт и импорт).

Это **PWA**: сайт, который ставится на главный экран телефона и работает без интернета. Сборки и сервера нет, данные хранятся на телефоне.

**21 файл, около 4,7 МБ.** В отличие от полной версии нет three.js и 3D-моделей, поэтому приложение быстрее открывается и меньше нагружает телефон.

## Как выложить в интернет и открыть на телефоне

Приложению нужен адрес в интернете (https): если просто скопировать файлы на телефон, офлайн-режим и установка работать не будут. Все способы ниже бесплатные.

### Вариант А. Netlify Drop — самый быстрый

1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop) на компьютере.
2. Перетащите в окно **папку `fitforge-lite` целиком**.
3. Через несколько секунд появится ссылка вида `https://<название>.netlify.app` — откройте её на телефоне.
4. Без регистрации сайт удаляется примерно через час. Чтобы он остался навсегда, зарегистрируйтесь — кнопка будет на той же странице.

### Вариант Б. GitHub Pages

1. На [github.com](https://github.com) нажмите **+ → New repository**. Название, например, `fitforge`, тип **Public**. Галочки README и `.gitignore` не ставьте. Нажмите **Create repository**.
2. Нажмите **uploading an existing file**. Откройте папку `fitforge-lite`, нажмите **Ctrl+A** и перетащите всё в окно браузера: 21 файл, одна загрузка. Нажмите **Commit changes**.
   - Перетаскивайте **содержимое** папки, а не саму папку: `index.html` должен лежать в корне.
   - Скрытые `.gitignore` и `.nojekyll` станут видны после **Вид → Показать → Скрытые элементы**. Без них тоже работает.
3. Откройте **Settings → Pages**, выберите **Deploy from a branch → main / (root)** и нажмите **Save**.
4. Через одну-две минуты сайт откроется по адресу `https://<логин>.github.io/fitforge/`.

## Установка на телефон

- **Android (Chrome):** откройте ссылку → **⋮ → Установить приложение**.
- **iPhone (Safari):** откройте ссылку → **Поделиться → На экран «Домой»**.

После первого открытия приложение работает без интернета.

> Данные хранятся на конкретном телефоне. Чтобы перенести их на другое устройство, сделайте **Профиль → Данные → Экспорт**, а на новом устройстве — **Импорт**.

## Обновление

После изменения файлов увеличьте версию в первой строке `sw.js` (`fitforge-lite-v1` → `fitforge-lite-v2`) и загрузите файлы заново. Иначе телефон может показывать старую версию из кэша.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Страница приложения |
| `css/styles.css` | Оформление, светлая и тёмная темы |
| `js/data.js` | 48 упражнений: техника, мышцы, инвентарь, позы |
| `js/generator.js` | Подбор тренировок и план на недели |
| `js/app.js` | Экраны, календарь, тренировка, аналитика |
| `js/figure.js` | Длительность анимаций и запасная фигурка |
| `thumbs/*.webp` | Анимации упражнений: 6 листов на персонажа, в каждом 8 упражнений по 12 кадров |
| `sw.js`, `manifest.webmanifest`, `icons/` | Офлайн-режим и установка на телефон |

Полная версия с вращаемыми 3D-моделями и инструментами разработки лежит в папке `fitforge`.

Приложение не заменяет консультацию врача или тренера. Если упражнение вызывает боль, прекратите его.
